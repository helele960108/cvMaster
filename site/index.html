macOS 与 Windows 上的原生剪贴板工具。应用不联网，不需要账号，默认不记录。

在 GitHub 查看源码

0.1.0 源码预览，暂不提供安装包，需要从源码构建。

四条承诺

不联网
应用不发起网络请求。没有账号、云同步、遥测、广告或崩溃上传，代码里没有 HTTP 客户端和 WebView。
只存在本机
历史、设置和原始内容都在本机用户目录。macOS 版把数据目录权限收紧为仅自己可读写。
默认不记录
由你手动开启，只记录开启后的新复制。锁屏、睡眠和安全输入期间自动跳过。
避开敏感内容
识别剪贴板的隐私标记，默认排除常见密码管理器。剪贴板内容不进日志，HTML 不渲染。

限制也写在这里：没有应用级静态加密；不是所有密码管理器都会设置隐私标记；检查文件引用时，系统可能访问你复制的云盘或网络共享路径。完整说明见隐私与数据说明。

macOS 26.5+（Apple Silicon，SwiftUI）与 Windows 10/11（.NET 10，WPF），两端都是原生应用。
