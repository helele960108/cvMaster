## 源码结构

`native/CVMaster/` 按职责分文件；跨文件扩展共享的状态在主类里声明，视图层只读取，修改必须经由主类的方法。

| 区域 | 文件 |
| --- | --- |
| 启动与菜单栏 | `CVMasterApp`（入口与浮层）、`StatusAppDelegate+Paste`（粘贴交接）、`StatusAppDelegate+Shortcut`（Carbon 热键）、`SingleInstanceLock` |
| 状态与用例 | `ClipboardLibrary` 及 `+Settings` / `+Capture` / `+Paste` / `+Groups`；`Preferences`（偏好键、默认值、浮层尺寸） |
| 采集 | `ClipboardMonitor`、`ClipboardCapturePolicy`、`SessionLockState` |
| 存储 | `HistoryStore` 及 `+SQLite` / `+Schema` / `+Query` / `+Mutation` / `+Groups` / `+Content` / `+Assets` / `+Thumbnails`；`FileAvailability`、`ThumbnailCache`、`ThumbnailPipeline` |
| 模型与限额 | `Models`、`StorageLimits`（限额与有界文本）、`ClipTimeRange` |
| 粘贴目标 | `PasteTarget`、`PasteHandoffPolicy`、`PasteFocusRestoration` |
| 界面 | `QuickPanelView`、`PermissionBanner`、`SidePreviewView`、`ClipCardContent`、`PanelInteraction`、`SourceAppIcon`、`PreferencesView`、`ShortcutRecorder`、`ExcludedApplicationsSettings` |

`native/Validation/` 的隔离回归入口为 `RegressionChecks.swift`，按主题拆为 `ChecksStorage` / `ChecksGroups` / `ChecksPrivacy` / `ChecksCapture` / `ChecksPaste` / `ChecksThumbnails` / `ChecksBenchmark`，共享夹具在 `CheckSupport.swift`；真实 AX 回归为 `AXChecks` + `AXTargetApp`。

## 运行形态

Apple Silicon、macOS 26.5、Swift 6、SwiftUI + AppKit。常驻菜单栏图标，无主窗口、无 Dock 图标。点击图标或全局 `⇧⌘V` 从图标下方展开唯一的 350 × 600 pt 浮层。点击外部、Esc 或执行粘贴时收起。

```bash
./native/scripts/build-app.sh
open ./native/.build/cvMaster.app
```

需要 macOS 26.5 SDK，无第三方依赖；使用系统 SQLite3、CryptoKit、ImageIO。构建脚本启用优化，输出到忽略目录 `native/.build/`，优先采用钥匙串中可用的 Apple Development / Mac Development 签名（可用 `CVMASTER_SIGNING_IDENTITY` 指定证书 SHA-1），保持同一证书下的更新身份稳定；没有证书时回退临时签名并警告。本机构建启用 hardened runtime，显式禁用联网时间戳；开发签名不等于 Developer ID 分发签名或公证。如果旧版本已运行，请先从更多菜单退出再打开新构建。

同一用户只允许一个客户端进程：启动器在 SwiftUI、菜单栏、剪贴板监控及历史库初始化前，获取 `Application Support/cvMaster/.instance.lock` 的非阻塞文件锁。安装版、开发 `.build` 及直接运行二进制共用此路径；已被占用时第二进程直接退出，不弹权限提示、不抢焦点。锁文件不随退出或清空历史删除，进程退出 / 崩溃后由内核释放锁；不要手工删除正在使用的锁文件。首次更新到本实现时，仍须先退出尚不遵守锁协议的旧版。

源码修改可执行静态检查和隔离命令行回归，不自动启动应用、采集真实剪贴板或打开真实应用数据库。运行前需自行构建；已有 `.build/` 产物不一定对应当前源码。隔离验证入口为 `./native/scripts/check-regressions.sh`，搜索基准可加 `--benchmark`，最长文本场景另加 `--benchmark-large`。涉及自动粘贴或 AX 的改动另跑 `./native/scripts/check-ax.sh`（或 `check-regressions.sh --ax`）；它会启动一个独立 AppKit 目标进程并验证真实跨进程焦点恢复，需要辅助功能权限。

## 权限引导

未获得辅助功能权限时，浮层在筛选下方显示情境式引导：可直接触发系统授权提示并打开“系统设置 → 隐私与安全性 → 辅助功能”，也可在本次运行内稍后关闭。设置 → 通用始终保留辅助功能状态、重新检测入口和旧 TCC 条目排查说明；授权状态在打开浮层、应用激活和进入设置时重新读取，不做定时轮询。记录剪贴板仍是用户开关，不是系统权限。

## 已接入的本地能力

- 首次启动记录默认关闭，用户明确开启后只采集新的变化，不回溯当前剪贴板。
- 每 500 ms 检查 changeCount，暂停、休眠、会话不在控制台 / 未登录完成、屏幕锁定或安全输入启用时跳过内容读取，缺失会话状态也保守阻断。macOS 锁屏状态以 `CGSSessionScreenIsLocked` 会话键为主、`com.apple.screenIsLocked` / `com.apple.screenIsUnlocked` 通知为低延迟补充；字典缺失或值异常按锁定处理，轮询间隔超过 5 秒时保守重置基线。阻断及恢复推进基线，不补采期间内容；锁屏还会作废尚未落盘的待处理快照。暂停状态跨重启保存；暂停时顶部显示“已暂停”，点击该状态可直接恢复记录。支持按应用选择排除来源和常见敏感 / 瞬时标记。未公开会话键与通知不能覆盖所有锁屏 / 密码情形，不宣称绝对安全边界。
- 纯文本、URL、PNG / TIFF / JPEG、文件 URL，以及同一条目中的 RTF / HTML 表示保存与恢复。不会执行 HTML 或自动加载远程资源。
- `changeCount` 仅表示剪贴板所有权代数，不保证数据已就绪。采集使用两阶段游标，首次观察后保留一个待处理代数；item / 类型列表尚空或必要表示暂不可读（nil）时，复用 500 ms 轮询，在首次尝试起 1.5 秒窗口内最多重试 3 次，不另建定时任务或保存待重试 Data。明确不支持、空数据、无效文件 URL、超限及敏感标记不反复重试；同 item 有其他可用格式时仍可回退。读取期间出现新代数由下一轮采集，不直接推进为已处理；同代数重试沿用首次观察的来源并重新检查排除项。
- 稳定内容指纹去重，重复复制更新时间与次数，保留原置顶和分组。
- SQLite 元数据、关系型分组、独立原始资产文件；原始内容不塞入 JSON 字段。schema v4 将已知中文分类迁移为稳定英文存储键，未知分类安全显示为文本但保留原值与原始复制表示。
- 搜索按类型做包含匹配：文本 / 链接匹配内容，文件仅匹配文件名，图片不参与非空关键词搜索（包括图片文件名）；空关键词正常显示图片。不检索分组名、文件路径或文件正文，分组 / 类型 / 时间仍可叠加筛选。支持置顶、新建 / 重命名 / 删除分组、分组手动排序、条目分组归属、删除记录、按时间清理与清空全部历史。
- 双击行、回车或右键“粘贴”先准备完整原始表示及临时剪贴板 item，再收起浮层、确认保存的目标应用仍存活且稳定处于前台 / active。打开列表时若捕获到原窗口 / 输入节点，则在写入前恢复并校验该节点；同一应用内切换到其他输入框、窗口变化或快照失效时拒绝，不把内容投递到错误位置。AX 快照不可用时退化为当前 active responder。写入后复核目标身份、前台状态、修饰键和截止时间，并向保存的目标 PID 发送 ⌘V；不使用全局 HID、模拟点击或自动提交。系统焦点检查与按键投递非原子，不能保证目标应用实际接收。授权不足或写入前准备失败不改写剪贴板；写入后失败提示可手动粘贴。迟到错误只在不会抢走其他应用焦点时重新显示列表。
- 移除底部预览，鼠标悬停条目 280 ms 后在侧边临时预览，离开后延迟 200 ms 关闭；也可通过右键“预览内容”或辅助功能操作打开，系统负责屏幕边缘位置调整。正文与小缩略图按需读取，文件引用恢复前检查可读性，引用失效给出错误而不删除原文件。
- 设置偏好使用 UserDefaults 的明确类型字段；记录状态、保留天数、排除来源列表及外观选择可保存。
- 历史保留支持 7 天、30 天、90 天、180 天、1 年和永久保留；永久保留只取消时间清理，条数与内容容量上限仍然生效。存储页分别展示全库已用条数、条数上限、已用内容量和内容上限，统计不受当前搜索或筛选影响。
- 存储页的“清理历史…”支持删除 1 小时、1 天、7 天、30 天或 1 年前的记录，以及清空全部；手动清理会包含所选时间点之前的置顶与分组内容，保留分组结构，不删除引用的原文件。
- 全局快捷键可在设置 → 通用录制并持久化，默认恢复为 ⇧⌘V；已有保存的组合保持不变，可点击“恢复默认”切换。录制时检查系统符号快捷键并处理 Carbon 注册失败，失败保留原快捷键。校验或注册失败时录制不退出，显示原因并响铃提示，可直接重试。仅 ⌘ 的组合会被拒绝，避免抢占复制、粘贴等菜单快捷键。
- 设置 → 通用支持“登录时启动”：使用系统 `SMAppService` 注册主应用，不安装额外 LaunchAgent；系统要求批准时显示状态并提供登录项入口。登录项按应用路径和签名管理，移动应用或更换签名后可能需要在系统设置中重新允许。
- 外观提供跟随系统、浅色和深色；应用代理统一同步应用、独立菜单栏浮层及宿主视图，SwiftUI 内容同时使用对应颜色方案，避免仅设置窗口生效。侧边预览、表单及原生材质继承同一偏好，重启后恢复；切回跟随系统时清除各层覆盖。

## 分组删除与手动排序

用户分组胶囊的右键菜单，以及更多 → 当前分组，提供重命名、前移、后移和删除分组。前移 / 后移交换相邻用户分组；“全部 / 置顶”固定在前，首组和末组分别禁用越界移动，不提供拖拽排序。顺序持久保存在既有 `position` 字段，重启后保留，条目“加入分组”菜单沿用同一顺序；排序不刷新历史页、不重置当前筛选、记录选择或分页。

删除前显示带分组名称的系统确认，只删除分组及其归属关系，不删除历史记录、原始表示或引用的原文件，也不立即触发保留策略清理。若完成时仍选中被删分组，则回到“全部”，保留关键词、类型及时间条件；否则不改变当前分组。删除最后一个所属分组后，记录未来可能按既有保留策略正常清理。

分组创建、重命名、删除和移动使用存储事务；移动在事务内按 UUID 读取最新目录并连续编号，新建使用最大位置加一，避免删除后的序号空洞影响追加位置。分组写入及目录回读期间禁用重复变更；失败不发布成功状态，缺失分组可控提示。沿用 schema v4，无需迁移，不重建条目或资产。

## 排除来源应用

“记录与隐私”以列表展示排除项，每行包含应用图标、名称和 Bundle ID，移除前会二次确认，无需手工编辑文本。添加时优先列出正在运行的应用；也可打开系统应用选择器添加已安装应用，手动输入 Bundle ID 仅作为找不到应用时的兜底。排除项仍以 Bundle ID 持久化，在采集前按来源判断，大小写不敏感；修改只影响之后的新复制，不删除已有历史。未安装或无法解析的应用保留 Bundle ID，并使用通用占位图标。

## 内存与响应约束

- UI 仅保留首屏 60 条轻量元数据；按需加载，最多 300 条，之后使用搜索缩小范围；关闭浮层缩回 60 条。
- 数据库读写、哈希、搜索、清理和应用资产读取在存储 actor 执行，不在主线程扫描历史。缩略图原图读取 / ImageIO 解码使用专属 GCD 队列最多两个实际未结束工作，零待执行工作队列；最多等待 3 秒，超时 / 取消不释放尚未真正结束的许可。busy 只做有界重试，真实失败进入有界冷却，避免异常挂载点不断新增阻塞线程。原文件引用的可读性检查也在 actor 外有界执行。
- 搜索 140 ms 防抖，3 个及以上 Unicode 码点在支持时先对 FTS5 trigram 做最多 1,024 个候选的有界探测：低于阈值才使用候选并以转义 LIKE 复核，达到阈值（高命中）直接顺序 LIKE；1–2 码点或能力不可用时同样回退 LIKE。结果集与索引选择无关。取消在查询入口 / 语句间 / 行间生效，不中断正在执行的 SQLite 语句；版本标识拒绝过期结果。分组一次批量读取，容量统计只在内容变更后重算。
- 一次最多一个采集写入，无无限增长的快照队列。处理期间新变化可能跳过，日志仅记录计数，不记录正文或路径。
- 单种表示最多 8 MB、单条总量最多 16 MB、最多 24 个表示；列表不持有原始内容。派生标题 / 摘要分别最多 120 字符 / 4 KiB、240 字符 / 8 KiB，整条搜索文本共享 32,768 字符 / 128 KiB 输出预算；来源显示名和 Bundle ID 各最多 1 KiB（超长 ID 置空，不截成另一身份）。以 Unicode scalar 安全截断，组合字素也不能绕过字节限额；原始复制表示不受这些元数据限额截断。搜索词最多 256 字符 / 8 KiB，分组名最多 20 字符 / 1 KiB，超限分组明确拒绝。
- 单个预览最多 16 KB 文本或 420 px 小图，展示图像只在结果变化时构造，关闭后释放引用；来源图标维持 MainActor 绘制与既有有界缓存，冷解析 / 栅格化提供无内容 signpost 供 Instruments 量测。
- SQLite 页缓存预算 2 MB、WAL 自动检查点、日志回收目标 4 MB；数据库与系统缓存不属于 Swift 数组预算。
- 内容容量最多 1 GB、总条数最多 10,000 条（包含保护条目）；入库时清理过期 / 超限非保护条目。受保护内容占满后拒绝新增。
- “1 GB”仅指原始表示总量，不是数据库 + trigram 索引 + WAL + 临时文件的硬磁盘配额。清理提交后 best-effort 回收孤立资产并 checkpoint，不同步执行全库 VACUUM；释放的数据库页保留复用，文件不保证立即缩小。

这些是代码约束，不是实测性能结果。最低硬件的 P95 唤起 / 搜索、空闲 CPU、峰值内存和长时间运行仍需 Instruments 验证，不能由静态检查推断通过。

## 隐私与兼容边界

数据位置为当前用户 Application Support 下的 `cvMaster` 目录。应用检查并收紧当前用户所有的目录权限为 0700，内容、数据库及已有 WAL / SHM / journal 为 0600；数据库在 SQLite 打开前以 0600 创建。拒绝应用根目录 / assets / DB / sidecar 及资产叶节点符号链接，资产使用目录描述符相对访问；不把这解释为对同 UID 恶意修改祖先目录的完全隔离。未实现应用级静态加密，删除不保证从 SSD、系统快照或备份安全擦除。日志不记录正文、完整路径或密钥。

系统剪贴板数据必须通过 AppKit 读取，延迟提供者读取前不能可靠获知大小；读取后立即检查预算，但无法承诺该系统调用永不短暂阻塞。轮询不保证捕获所有瞬时复制。

文件只保存引用，不拷贝文件本体，不提供长期 sandbox bookmark 授权；当前非沙盒本机版本的可访问性不代表未来沙盒发行版。文件移动或权限失效后不能恢复。图片超限、私有格式、file promise 暂不支持。RTF-only 可在后台按 256 KiB 预算提取摘要 / 搜索文本 / 详情；HTML-only 保留原始格式但不渲染、不提取正文。

未实现批量多选整理、同步、账号或移动端；RTF 仅提取有界纯文字，不作富文本样式渲染。不宣称敏感识别或推断来源完全可靠。全局热键注册失败时保留图标入口；多屏、全屏、菜单栏自动隐藏和 VoiceOver 完整行为尚待人工验收。

## 应用图标

使用已确认的单色圆润 CV 字标，不再保留暖白 / 铜橙剪贴板图案或彩色底板。矢量源为 `Resources/AppIcon.svg`，透明深色主图为 `Resources/AppIcon.png`，标准 macOS 多尺寸图标为 `Resources/AppIcon.icns`，由 `CFBundleIconFile` 引用。

更换主图后执行 `./native/scripts/generate-icon.sh`，生成 16–1024 px 普通与 Retina 尺寸及 `Resources/StatusIcon.png`，再构建应用。菜单栏使用单独裁去留白的 CV 透明模板图，最长边 18 pt、保持宽高比，由系统适配明暗和选中态；不添加底板或圆角裁剪。图标仅在启动时加载，资源不可用时回退到系统剪贴板符号。Windows 图标也由该主图派生；安装 Python / Pillow 后，可执行 `python3 windows/tools/check-icons.py` 检查两端资源一致性。

## 纯文本粘贴

文本与链接条目的右键菜单提供“粘贴为纯文本”，其他类型隐藏。仅写入纯文本类型，移除字体、颜色及富文本表示，再按普通粘贴流程恢复原输入节点（有 AX 快照时）并发送 ⌘V；辅助功能权限不足时提示授权且不改写剪贴板。同一应用内切换到其他输入框或窗口变化时拒绝恢复；快照不可用时由当前 responder 接收。只发送粘贴快捷键，不保证只读控件或目标应用一定接收，不自动提交内容。

文本优先使用原始纯文本；链接优先使用 URL 地址，RTF 在后台提取文字。多 item 按顺序换行合并，不使用已截断的列表摘要或预览。实际解析的 RTF 共享 256 KiB 输入预算，超限明确拒绝且不改变剪贴板，不影响普通原格式粘贴或超过 256 KiB 的纯 UTF-8 文本。只有 HTML 且没有纯文本 / URL / RTF 的记录会明确提示无法转换，不调用 HTML 渲染器加载潜在远程资源。原历史格式保持不变。

## 侧图微卡片列表

列表采用原生微卡片：文本摘要优先、来源与时间沉底，图片在卡片上方等比填充；使用系统背景和细选中边框。图片只在卡片出现时后台生成最长边 640 px 缩略图；actor 缓存最多 24 张、2 MB，卡片离开后释放自身图像引用，删除与清空会同步清理缓存。失败使用系统类型占位，不影响文字展示和原始复制；侧边预览仍独立按需加载最长边 420 px 的图片。

## 内容展示与高度调整

卡片正文占用上部完整内容区域，文本 / 链接最多四行、尾部省略，不再将首行截短后另列重复摘要。文件主体最多三行，长名称省略但独立保留末尾扩展名；多文件从摘要首个文件名提取后缀。列表仍只使用有界摘要，不为更多行读取完整原始内容。

浮层手柄位于远离菜单栏图标的一侧：常规顶部菜单栏布局下手柄在底部，浮层翻到图标上方时自动移到顶部，拖动方向也随之反转。手柄支持上下拖动调整高度，宽度保持 350 pt；常规范围 420–1000 pt，实际高度受当前屏幕可用空间限制。松开后保存高度，重新打开恢复；顶部和底部控件固定，列表随高度变化。也支持辅助功能增减高度。手柄悬停时高亮并显示上下调整光标；拖动采用稳定屏幕坐标，最多保留一个约 60 Hz 的待执行尺寸更新，关闭浮层时取消。尺寸由原生容器管理，不在每次拖动时发布整个列表状态，不启用连续缩放动画。分组、类型和列表操作按钮提供统一的悬停及按下反馈。

列表卡片不再显示右侧箭头，正文使用完整可用宽度。图片记录以 160 pt 固定高度铺满卡片（等比填充裁切），图片下方保留来源应用图标 / 名称、相对时间、类型图标和置顶状态；悬停预览显示图片详情、来源和大小，也可通过右键“预览内容”或辅助功能操作打开。列表图片后台降采样至最长边 640 px，沿用 24 张 / 2 MB 缓存预算，不加载原图。

## 相对时间与时间筛选

列表以“刚刚 / N 分钟前 / N 小时前 / 昨天 / N 天前”显示最近复制时间，7 天及以上显示日期。时间标签每分钟独立刷新，不触发历史查询或缩略图重新加载；悬停时间标签可查看完整时间，图片完整时间在侧边预览中展示。

时间筛选采用搜索栏时钟方案：入口固定在搜索框右侧，默认不展示选项；点击打开 macOS 原生菜单，不增加筛选行或挤压列表。支持全部时间、今天、昨天、近 7 天、近 30 天，菜单勾选当前范围。存在时间限制时，时钟使用强调色、淡色背景和小圆点，搜索框为空时同时在占位提示中显示当前范围；悬停与辅助功能始终可读出当前范围。近 N 天按当前系统日历和时区计算，包含今天及此前 N−1 个自然日。条件与分组、类型、关键词叠加，在 SQLite 层、分页之前执行，计数和加载更多使用同一条件。时间范围不持久化，重启后恢复全部时间；菜单打开、关闭及清除搜索文本均不改变已选时间条件，选择“全部时间”可取消时间限制。

## 图片文件引用预览

从访达、微信等应用复制 JPG / PNG 等图片文件时，剪贴板可能只提供 `public.file-url`，而非图片像素。单个图片文件现在以图片卡片展示，列表和侧边预览均可按需从原文件生成缩略图，已有历史记录同样适用；复制操作仍写回文件引用，不擅自改成图片像素。图片文件归入“图片”类型筛选；原始文件引用保持不变。

文件引用不等于图片备份：原文件移动、删除或无读取权限时无法生成新预览。预览仅处理本地普通图片文件，跳过叶节点符号链接、网络卷、未下载的云文件及超过 64 MiB 的文件。通过 no-follow 文件描述符读入有界压缩 Data 后交给 ImageIO 降采样，不把检查过的 URL 再次打开；两个工作最坏可持有 128 MiB 原始压缩输入，另有 ImageIO 临时缓冲。云状态等元数据存在竞态，不能保证所有文件系统调用及时返回。stored 像素的 640 / 420 px 两种缓存共享 24 张 / 2 MiB 预算，引用不长期缓存。不可用时保留占位与说明，不改写或删除原文件。


## 多格式采集与预览回退

- 栅格图片白名单由采集和预览共用，覆盖 PNG、JPEG、TIFF、HEIC、HEIF、GIF、BMP、WebP；实际解码依赖系统 ImageIO，动画仅预览首帧。首个声明格式无数据或超过单表示预算时继续尝试其他图片格式，成功保存后才认定为图片。
- 剪贴板同时提供文件引用和图片像素时，两者均保留，不自动读取引用文件备份。记录归入“图片”，再次复制不改变文件语义；源文件不可用时，已保存的像素表示仍可用于预览。
- RTF-only 内容在后台有界提取摘要、搜索文本和详情；单次解析预算 256 KB。HTML-only 不使用可能加载外部资源的渲染器；继续保留原始格式，可正常复制，但不承诺文本预览。
- 一个资产缺失不再中断其他表示的预览；多文件详情按原顺序显示引用，图片预览使用首个可解码图片。复制仍校验全部资产和引用，避免悄悄只恢复部分文件；临时剪贴板 item 设置失败时，不清空现有剪贴板。
- 单个图片文件的识别优先采用摘要里的文件名后缀，避免标题截断影响判断。已下载的本地云文件可以预览，未下载内容不主动下载；外部引用不进入长期缩略图缓存。图片预览失败有明确提示。

以上能力仍未进行真实来源应用（如微信、浏览器、编辑器）的完整交互回归。真实 AX 回归已覆盖独立 AppKit 目标进程的原输入节点捕获、恢复和“切换到其他输入框必须拒绝”；完整门禁与来源应用兼容性仍需人工验收。本轮增加仅用合成内容和临时目录的命令行回归；其执行结果及性能基准见[修复验证记录](../docs/修复验证记录.md)。旧 RTF 记录可按需预览提取，但不会批量补齐旧记录原本缺失的标题或搜索文本；trigram 仅为已有 search_text 构建索引。旧文件引用无法追溯补回当时未保存的像素数据。

## 容量拒绝、关闭查询与多条目文本

- 清理前核算受保护记录；即使删除全部非保护内容仍放不下时直接拒绝。清理、去重更新时间及新增入库共享事务，文件写入或 SQL 失败会回滚历史元数据；旧资产只在成功提交后 unlink，新资产失败回收。
- 关闭浮层时取消列表查询并使查询版本失效，同时重置加载状态；已在后台执行的旧查询不能重新发布超过首屏 60 条的列表。
- 新采集的多条目纯文本 / URL 按原顺序聚合搜索文本，共享 32,768 字符预算；同一条目的多种表示不重复索引。详情对已有记录同样按条目顺序展示，优先文件引用、纯文本、URL，再回退 RTF，共享 16 KB 文本与 256 KB RTF 解析预算。原始复制表示不变；旧记录的搜索索引不批量重建，超过索引预算的内容不保证可搜索。


图片分类与复制表示相互独立：仅图片文件（含多张图片）归入“图片”；图片与其他文件混合复制仍归“文件”。数据库 v3 启动迁移会根据文件名和引用数量修正可确认的旧图片文件分类，不修改资产、复制次数、置顶及分组关系；不完整的多文件摘要保守保留原分类。图片预览仍按需读取；引用提示由原始文件表示判断，而非可见类型。

图片与其他卡片共用底部元信息视图；图片上部保持 160 pt 等比填充，底部为独立信息栏，不遮挡图片，也不恢复右侧箭头。

图片区域四角使用连续圆角，底边与信息栏自然分隔，外层卡片仍保留统一圆角。侧边预览不显示文件路径：图片左上角使用来源应用图标和名称替代类型标题，保留图像、时间和置顶操作，不显示文件名及底部引用 / 大小说明，普通文件 / 多文件仅展示文件名；内部文件引用和再次复制行为不变。
