# cvMaster 本地剪贴板工具

> author：helele
>
> since：2026-10-19

## 运行形态

Apple Silicon、macOS 26.5、Swift 6、SwiftUI + AppKit。常驻菜单栏图标，无主窗口、无 Dock 图标。点击图标或全局 `⌥Space` 从图标下方展开唯一的 350 × 600 pt 浮层。点击外部、Esc 或执行粘贴时收起。

```bash
./native/scripts/build-app.sh
open ./native/.build/cvMaster.app
```

需要 macOS 26.5 SDK，无第三方依赖；使用系统 SQLite3、CryptoKit、ImageIO。构建脚本启用优化，输出到忽略目录 `native/.build/`，优先采用钥匙串中可用的 Apple Development / Mac Development 签名（可用 `CVMASTER_SIGNING_IDENTITY` 指定证书 SHA-1），保持同一证书下的更新身份稳定；没有证书时回退临时签名并警告。开发签名不等于 Developer ID 分发签名或公证。如果旧版本已运行，请先从更多菜单退出再打开新构建。

源码修改采用静态检查，不自动启动采集真实剪贴板。运行前需自行构建；已有 `.build/` 产物不一定对应当前源码。

## 权限引导

未获得辅助功能权限时，浮层在筛选下方显示情境式引导：可直接触发系统授权提示并打开“系统设置 → 隐私与安全性 → 辅助功能”，也可在本次运行内稍后关闭。设置 → 通用始终保留辅助功能状态、重新检测入口和旧 TCC 条目排查说明；授权状态在打开浮层、应用激活和进入设置时重新读取，不做定时轮询。记录剪贴板仍是用户开关，不是系统权限。

## 已接入的本地能力

- 首次启动记录默认关闭，用户明确开启后只采集新的变化，不回溯当前剪贴板。
- 每 500 ms 检查 changeCount，暂停或休眠时跳过内容读取；支持按应用选择排除来源和常见敏感 / 瞬时标记。
- 纯文本、URL、PNG / TIFF / JPEG、文件 URL，以及同一条目中的 RTF / HTML 表示保存与恢复。不会执行 HTML 或自动加载远程资源。
- 稳定内容指纹去重，重复复制更新时间与次数，保留原置顶和分组。
- SQLite 元数据、关系型分组、独立原始资产文件；原始内容不塞入 JSON 字段。
- 搜索按类型做包含匹配：文本 / 链接匹配内容，文件仅匹配文件名，图片不参与非空关键词搜索（包括图片文件名）；空关键词正常显示图片。不检索分组名、文件路径或文件正文，分组 / 类型 / 时间仍可叠加筛选。支持置顶、新建 / 重命名分组、条目分组归属、删除、按时间清理与清空全部历史。
- 双击行、回车或右键“粘贴”先恢复原始剪贴板表示，再清除搜索框 first responder、隐藏浮层并释放 key window，恢复打开前的外部应用输入焦点，向保存的外部进程定向发送 ⌘V（不使用全局 HID 路由）。需要辅助功能授权；每次启动最多触发一次系统授权提示，其余失败仅显示应用内说明。若已开启但仍显示未授权，尤其由临时签名切换开发签名后，请在辅助功能中移除旧条目，重新添加 `~/Applications/cvMaster.app` 并授权、重启。能够获取输入节点时校验其可编辑性及焦点一致；目标未暴露 AX 输入节点时，确认恢复到原应用、原窗口后发送标准 ⌘V，由目标窗口处理，不模拟点击或提交。窗口变化时不发送按键。自写内容不重新入库。
- 移除底部预览，鼠标悬停条目 280 ms 后在侧边临时预览，离开后延迟 200 ms 关闭；行尾箭头仍支持点击，系统负责屏幕边缘位置调整。正文与小缩略图按需读取，文件引用恢复前检查可读性，引用失效给出错误而不删除原文件。
- 设置偏好使用 UserDefaults 的明确类型字段；记录状态、保留天数、排除来源列表及外观选择可保存。
- 历史保留支持 7 天、30 天、90 天、180 天、1 年和永久保留；永久保留只取消时间清理，条数与内容容量上限仍然生效。存储页分别展示全库已用条数、条数上限、已用内容量和内容上限，统计不受当前搜索或筛选影响。
- 存储页的“清理历史…”支持删除 1 小时、1 天、7 天、30 天或 1 年前的记录，以及清空全部；手动清理会包含所选时间点之前的置顶与分组内容，保留分组结构，不删除引用的原文件。
- 全局快捷键可在设置 → 通用录制并持久化，默认恢复为 ⌥Space；录制时检查系统符号快捷键并处理 Carbon 注册失败，失败保留原快捷键。校验或注册失败时录制不退出，显示原因并响铃提示，可直接重试。仅 ⌘ 的组合会被拒绝，避免抢占复制、粘贴等菜单快捷键。
- 设置 → 通用支持“登录时启动”：使用系统 `SMAppService` 注册主应用，不安装额外 LaunchAgent；系统要求批准时显示状态并提供登录项入口。登录项按应用路径和签名管理，移动应用或更换签名后可能需要在系统设置中重新允许。
- 外观提供跟随系统、浅色和深色；应用代理统一同步应用、独立菜单栏浮层及宿主视图，SwiftUI 内容同时使用对应颜色方案，避免仅设置窗口生效。侧边预览、表单及原生材质继承同一偏好，重启后恢复；切回跟随系统时清除各层覆盖。

## 排除来源应用

“记录与隐私”以列表展示排除项，每行包含应用图标、名称和 Bundle ID，移除前会二次确认，无需手工编辑文本。添加时优先列出正在运行的应用；也可打开系统应用选择器添加已安装应用，手动输入 Bundle ID 仅作为找不到应用时的兜底。排除项仍以 Bundle ID 持久化，在采集前按来源判断，大小写不敏感；修改只影响之后的新复制，不删除已有历史。未安装或无法解析的应用保留 Bundle ID，并使用通用占位图标。

## 内存与响应约束

- UI 仅保留首屏 60 条轻量元数据；按需加载，最多 300 条，之后使用搜索缩小范围；关闭浮层缩回 60 条。
- 数据库读写、哈希、搜索、清理、资产读取和图像降采样在专用 actor 串行执行，不在主线程扫描历史或解码原图；引用文件缩略图在存储 actor 之外生成，单次最多等待 3 秒，异常挂载点超时后本次运行跳过，不阻塞列表查询与入库。
- 搜索 140 ms 防抖，取消尚未执行的旧查询，用版本标识拒绝过期结果；正在执行的 SQLite 查询不会被中断。
- 一次最多一个采集写入，无无限增长的快照队列。处理期间新变化可能跳过，日志仅记录计数，不记录正文或路径。
- 单种表示最多 8 MB、单条总量最多 16 MB、最多 24 个表示；列表不持有原始内容。单个预览最多 16 KB 文本或 420 px 小图，关闭即释放引用。
- SQLite 页缓存预算 2 MB、WAL 自动检查点、日志回收目标 4 MB；数据库与系统缓存不属于 Swift 数组预算。
- 内容容量最多 1 GB、非保护条数最多 10,000 条；入库时清理过期 / 超限非保护条目。受保护内容占满后拒绝新增。
- “1 GB”当前指原始表示总量，不是数据库 + WAL + 临时文件的硬磁盘配额；清空或按时间清理后执行 checkpoint 与 VACUUM。

这些是代码约束，不是实测性能结果。最低硬件的 P95 唤起 / 搜索、空闲 CPU、峰值内存和长时间运行仍需 Instruments 验证，不能由静态检查推断通过。

## 隐私与兼容边界

数据位置为当前用户 Application Support 下的 `cvMaster` 目录。目录权限 0700，内容与数据库 0600；未实现应用级静态加密，删除不保证从 SSD、系统快照或备份安全擦除。日志不记录正文、完整路径或密钥。

系统剪贴板数据必须通过 AppKit 读取，延迟提供者读取前不能可靠获知大小；读取后立即检查预算，但无法承诺该系统调用永不短暂阻塞。轮询不保证捕获所有瞬时复制。

文件只保存引用，不拷贝文件本体，不提供长期 sandbox bookmark 授权；当前本机临时签名、非沙盒版本可访问性不代表未来沙盒发行版。文件移动或权限失效后不能恢复。图片超限、私有格式、file promise 暂不支持；仅含 RTF / HTML 的内容可恢复，但当前不提取全文进行搜索或安全渲染。

未实现分组删除 / 排序、富文本预览、同步、账号或移动端。不宣称敏感识别或推断来源完全可靠。全局热键注册失败时保留图标入口；多屏、全屏、菜单栏自动隐藏和 VoiceOver 完整行为尚待人工验收。

## 应用图标

暂用用户确认的暖白 / 铜橙剪贴板图案。原图保存在 `Resources/AppIcon.png`，标准 macOS 多尺寸图标为 `Resources/AppIcon.icns`，打包时复制到应用资源目录，由 `CFBundleIconFile` 引用。

更换原图后执行 `./native/scripts/generate-icon.sh` 重新生成 16–1024 px 普通与 Retina 尺寸，再构建应用。源图保持原样，不额外裁切或改变背景。菜单栏同样使用该图标，以 18 pt 彩色方式显示，启动时一次性生成透明圆角小图，柔化方形背景边缘；资源不可用时回退到系统剪贴板符号。

## 纯文本粘贴

文本与链接条目的右键菜单提供“粘贴为纯文本”，其他类型隐藏。仅写入纯文本类型，移除字体、颜色及富文本表示，再按普通粘贴流程恢复原输入焦点并发送 ⌘V；辅助功能权限不足时提示授权且不改写剪贴板。目标应用未暴露输入节点时以原应用 / 原窗口作为恢复边界；只发送粘贴快捷键，不保证只读控件或目标应用一定接收，不自动提交内容。

文本优先使用原始纯文本；链接优先使用 URL 地址，RTF 在后台提取文字。多 item 按顺序换行合并，不使用已截断的列表摘要或预览。只有 HTML 且没有纯文本 / URL / RTF 的记录会明确提示无法转换，不调用 HTML 渲染器加载潜在远程资源，不改变当前剪贴板。原历史格式保持不变，普通“复制”仍恢复原始表示。

## 侧图微卡片列表

列表采用已选定的侧图微卡片：图片左置、文本摘要、来源与时间沉底，卡片使用系统背景和细选中边框。图片只在卡片出现时后台生成最长边 152 px 缩略图；actor 缓存最多 24 张、2 MB，卡片离开后释放自身图像引用，删除与清空会同步清理缓存。失败使用系统类型占位，不影响文字展示和原始复制；侧边预览仍独立按需加载。

## 内容展示与高度调整

卡片正文占用上部完整内容区域，文本 / 链接最多四行、尾部省略，不再将首行截短后另列重复摘要。文件主体最多三行，长名称省略但独立保留末尾扩展名；多文件从摘要首个文件名提取后缀。列表仍只使用有界摘要，不为更多行读取完整原始内容。

浮层底部手柄支持上下拖动调整高度，宽度保持 350 pt；常规范围 420–1000 pt，实际高度受当前屏幕可用空间限制。松开后保存高度，重新打开恢复；顶部和底部控件固定，列表随高度变化。也支持辅助功能增减高度。手柄悬停时高亮并显示上下调整光标；拖动采用稳定屏幕坐标，最多保留一个约 60 Hz 的待执行尺寸更新，关闭浮层时取消。尺寸由原生容器管理，不在每次拖动时发布整个列表状态，不启用连续缩放动画。分组、类型和列表操作按钮提供统一的悬停及按下反馈。

列表卡片不再显示右侧箭头，正文使用完整可用宽度。图片记录以 160 pt 固定高度铺满卡片（等比填充裁切），图片下方保留来源应用图标 / 名称、相对时间、类型图标和置顶状态；悬停预览显示图片详情、来源和大小，也可通过右键“预览内容”或辅助功能操作打开。列表图片后台降采样至最长边 640 px，沿用 24 张 / 2 MB 缓存预算，不加载原图。

## 相对时间与时间筛选

列表以“刚刚 / N 分钟前 / N 小时前 / 昨天 / N 天前”显示最近复制时间，7 天及以上显示日期。时间标签每分钟独立刷新，不触发历史查询或缩略图重新加载；悬停时间标签可查看完整时间，图片完整时间在侧边预览中展示。

时间筛选采用搜索栏时钟方案：入口固定在搜索框右侧，默认不展示选项；点击打开 macOS 原生菜单，不增加筛选行或挤压列表。支持全部时间、今天、昨天、近 7 天、近 30 天，菜单勾选当前范围。存在时间限制时，时钟使用强调色、淡色背景和小圆点，搜索框为空时同时在占位提示中显示当前范围；悬停与辅助功能始终可读出当前范围。近 N 天按当前系统日历和时区计算，包含今天及此前 N−1 个自然日。条件与分组、类型、关键词叠加，在 SQLite 层、分页之前执行，计数和加载更多使用同一条件。时间范围不持久化，重启后恢复全部时间；菜单打开、关闭及清除搜索文本均不改变已选时间条件，选择“全部时间”可取消时间限制。

## 图片文件引用预览

从访达、微信等应用复制 JPG / PNG 等图片文件时，剪贴板可能只提供 `public.file-url`，而非图片像素。单个图片文件现在以图片卡片展示，列表和侧边预览均可按需从原文件生成缩略图，已有历史记录同样适用；复制操作仍写回文件引用，不擅自改成图片像素。图片文件归入“图片”类型筛选；原始文件引用保持不变。

文件引用不等于图片备份：原文件移动、删除或无读取权限时无法生成新预览。预览仅处理本地普通图片文件，跳过符号链接、网络卷、未下载的云文件及超过 64 MB 的文件；后台使用 ImageIO 降采样，不把原文件整体读入内存，不触发云文件下载。像素数据缩略图复用现有有界缓存，文件引用不长期缓存，避免原文件变化后展示旧图。不可用时列表保留文件名与说明，不改写或删除历史记录。


## 多格式采集与预览回退

- 栅格图片白名单由采集和预览共用，覆盖 PNG、JPEG、TIFF、HEIC、HEIF、GIF、BMP、WebP；实际解码依赖系统 ImageIO，动画仅预览首帧。首个声明格式无数据或超过单表示预算时继续尝试其他图片格式，成功保存后才认定为图片。
- 剪贴板同时提供文件引用和图片像素时，两者均保留，不自动读取引用文件备份。记录归入“图片”，再次复制不改变文件语义；源文件不可用时，已保存的像素表示仍可用于预览。
- RTF-only 内容在后台有界提取摘要、搜索文本和详情；单次解析预算 256 KB。HTML-only 不使用可能加载外部资源的渲染器；继续保留原始格式，可正常复制，但不承诺文本预览。
- 一个资产缺失不再中断其他表示的预览；多文件详情按原顺序显示引用，图片预览使用首个可解码图片。复制仍校验全部资产和引用，避免悄悄只恢复部分文件；临时剪贴板 item 设置失败时，不清空现有剪贴板。
- 单个图片文件的识别优先采用摘要里的文件名后缀，避免标题截断影响判断。已下载的本地云文件可以预览，未下载内容不主动下载；外部引用不进入长期缩略图缓存。图片预览失败有明确提示。

以上为静态审查修复，未进行真实来源应用的交互回归；旧 RTF 记录可按需预览提取，但不会批量重建旧记录的标题及搜索索引。旧文件引用无法追溯补回当时未保存的像素数据。

## 容量拒绝、关闭查询与多条目文本

- 清理前先核算受保护记录的条数和表示字节数；即使删除全部非保护记录也无法容纳新内容时，直接拒绝，不因本次容量拒绝删除已有历史。此预检不等同于文件写入失败时的全流程回滚保证。
- 关闭浮层时取消列表查询并使查询版本失效，同时重置加载状态；已在后台执行的旧查询不能重新发布超过首屏 60 条的列表。
- 新采集的多条目纯文本 / URL 按原顺序聚合搜索文本，共享 32,768 字符预算；同一条目的多种表示不重复索引。详情对已有记录同样按条目顺序展示，优先文件引用、纯文本、URL，再回退 RTF，共享 16 KB 文本与 256 KB RTF 解析预算。原始复制表示不变；旧记录的搜索索引不批量重建，超过索引预算的内容不保证可搜索。


图片分类与复制表示相互独立：仅图片文件（含多张图片）归入“图片”；图片与其他文件混合复制仍归“文件”。数据库 v3 启动迁移会根据文件名和引用数量修正可确认的旧图片文件分类，不修改资产、复制次数、置顶及分组关系；不完整的多文件摘要保守保留原分类。图片预览仍按需读取；引用提示由原始文件表示判断，而非可见类型。

图片与其他卡片共用底部元信息视图；图片上部保持 160 pt 等比填充，底部为独立信息栏，不遮挡图片，也不恢复右侧箭头。

图片区域四角使用连续圆角，底边与信息栏自然分隔，外层卡片仍保留统一圆角。侧边预览不显示文件路径：图片左上角使用来源应用图标和名称替代类型标题，保留图像、时间和置顶操作，不显示文件名及底部引用 / 大小说明，普通文件 / 多文件仅展示文件名；内部文件引用和再次复制行为不变。
