# cvMaster UI 设计说明

> 状态：v0.2 菜单栏轻量浮层，替代早期三栏主窗口方案。
>
> author：helele
>
> since：2026-10-19

## 1. 产品形态

这是小而强悍的菜单栏工具，不是带资料库主窗口的常规应用。日常只保留菜单栏图标，不显示 Dock 图标、不自动打开操作窗口。

点击图标或全局快捷键，从图标下方唤出同一浮层。查找、切换分组、复制、置顶等核心动作均集中在这里；点击外部或 Esc 收起。设置仅是次级辅助窗口。

原生实现位于 `native/`，使用 SwiftUI + AppKit，目标为 Apple Silicon / macOS 26.5。早期 `design/ui/` 三栏浏览器稿仅保留为视觉探索，不再代表当前交互方向。

## 2. 视觉与结构

沿用暖中性色、低饱和铜橙强调和 SF Symbols。外观支持跟随系统、浅色和深色，在设置中切换并持久保存；浮层和设置使用同一应用级外观，跟随系统时不固定颜色；采用 NSPopover 原生材质与系统菜单，不叠加大面积装饰性玻璃。

浮层参考尺寸为 350 × 600 pt，不使用窗口红绿灯、侧栏、大标题、独立检查器或永久工具面板。

从上到下仅有：

1. 小标题与“…”更多入口，暂停时显示状态。
2. 单行搜索，支持清除，不放营销文案。
3. 横向分组切换：全部、置顶、用户分组；下方独立一排“全部类型 / 文本 / 链接 / 图片 / 文件”直接筛选，按钮命中区域覆盖周围留白。
4. 单列侧图微卡片：图片左侧小缩略图、文件引用图标，正文显示标题与摘要；来源应用图标、名称、时间沉底，置顶和类型用小标记表示。选中态使用细铜橙边框，卡片间距 9 pt，避免大面积底色。
5. 条目悬停后在侧边显示临时预览，不占用主列表高度；空间不足时由系统调整弹出位置。
6. 一行记录数 / 操作反馈与热键提示，不设置大号复制按钮。

默认视图不展现容量、同步、来源统计、复杂管理或无用说明。界面不显示开发阶段标记或无关说明。

## 3. 操作规则

| 操作 | 入口 / 行为 |
| --- | --- |
| 唤起与收起 | 点击菜单栏图标或全局 `⌥Space`，同一浮层开关 |
| 搜索 | 展开时聚焦搜索；文本 / 链接按内容包含匹配，文件仅按文件名包含匹配；图片不参与关键词搜索，空关键词正常显示；分组仅作独立筛选 |
| 切换范围 | 上排分组胶囊，下排类型按钮；两者组合筛选，无需展开菜单 |
| 选择与粘贴 | 上下键或单击行选择，回车或双击行粘贴到原输入位置 |
| 查看全文 | 鼠标停留 280 ms 自动侧边预览；行尾箭头保留点击入口。离开后延迟 200 ms 关闭，允许进入预览选择文字 |
| 置顶 / 分组 / 删除 | 条目右键菜单；预览中可直接置顶 |
| 分组管理 | 更多菜单中创建，当前分组可重命名 |
| 暂停 / 设置 / 退出 | 顶部更多菜单 |
| 登录时启动 | 设置 → 通用开关；使用系统登录项，需批准时提示并可打开登录项设置 |
| 失效文件 | 提示失效、禁用复制，仍可展开详情或删除记录 |
| 删除记录 | 系统二次确认，不删除原文件 |
| 无结果 | 简短空状态，不展示管理指引或额外面板 |

分组为多对多，置顶为全局属性；同一筛选内置顶优先，其余按最近复制时间排序。当前暂未实现分组删除、排序与批量操作。

## 4. 原生实现与权限

- NSStatusItem：唯一常驻入口。
- NSPopover（transient）：锚定图标、点击外部关闭、无常规主窗口。
- SwiftUI：搜索、分组、懒加载列表、按需预览与设置。
- RegisterEventHotKey：注册单一全局快捷键，不采集按键、不要求辅助功能授权；冲突或安装失败时明确提示，图标入口始终可用。
- 辅助功能：未授权时在浮层显示情境式引导，设置 → 通用提供状态、重新检测和旧条目排查；授权状态在打开浮层与应用激活时重新读取。
- 登录时启动：使用 SMAppService 注册主应用，不生成 LaunchAgent；状态以系统登录项为准，需要批准时从设置页打开登录项。
- LSUIElement / accessory 激活策略：不显示 Dock 图标。
- Settings Scene：次级设置，不提供“打开管理窗口”入口。

全屏、多显示器、菜单栏自动隐藏与快捷键占用等仍需完整兼容性验证。当前快捷键不可自定义，后续设置中提供录制及冲突检查。

## 5. 当前实现边界

当前源码已接入本地真实采集与持久化：首次默认关闭，用户明确开启后记录新复制内容。成功写回系统剪贴板后收起浮层，失败保留列表并反馈；不联网、不使用 JSON 字段存储业务数据。列表分页、后台存储和按需预览等限制见 `性能与实现约束.md`。

正式版不因失焦自动粘贴；内容预览采用安全纯文本或受控格式。敏感标记识别不能承诺过滤所有密码，文件记录也不等于文件备份。

## 6. 验证要求

静态检查包括 Swift 类型检查、脚本语法、plist、资源引用及 Git 差异检查。不创建单元测试类，不使用 Maven，不格式化无关代码。为实际查看原生效果可执行构建与本机临时签名，不能把构建成功视为交互或性能验收完成。

人工检查重点：图标唯一、无启动主窗口、弹出锚定位置、搜索焦点、全局热键、点击外部关闭、快捷分组切换、空结果、失效文件、侧边预览悬停、屏幕边缘位置和设置返回。所有新增修改加入暂存区，不提交、不推送。
