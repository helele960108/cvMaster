# cvMaster Windows 版设计

> 状态：v0.1.0，原生 Windows 托盘实现
>
> author：helele
>
> since：2026-10-19

本文记录 Windows 版在保持 macOS 产品约束前提下的技术选型、平台差异、安全边界与验收结果。产品目标、数据语义与视觉语言仍以 `概要设计.md`、`UI设计.md`、`性能与实现约束.md` 为基准；本文只描述 Windows 的落地方式与有意差异。

## 1. 目标与边界

Windows 版要解决的核心问题与 macOS 版一致：在任意应用里复制内容后，通过一个轻量入口快速找回并粘贴回原输入位置。它不是全功能剪贴板资料库，不提供常驻主窗口、云同步、账号体系或跨设备能力。

明确不做：

- 不联网，不上传剪贴板，不接入遥测。
- 不使用 WebView / Electron / 浏览器运行时。
- 不要求管理员权限，不提权、不绕过 UIPI。
- 不把业务对象序列化为 JSON 字段；元数据用关系表，内容用独立资产文件。
- 不在日志中记录剪贴板正文、文件名、完整路径或进程名。
- 不把敏感标记识别宣传为“密码绝对安全”。

## 3. 与 macOS 版的映射

| 能力 | macOS | Windows |
| --- | --- | --- |
| 常驻入口 | `NSStatusItem` | `Shell_NotifyIcon` 托盘图标 |
| 浮层 | `NSPopover`（transient） | 无边框 `Window`，托盘锚定，失焦自动收起 |
| 全局热键 | `RegisterEventHotKey`，`⌥Space` | `RegisterHotKey`，`Alt+Space`，`MOD_NOREPEAT` |
| 剪贴板监听 | `NSPasteboard` 500 ms 轮询 | `AddClipboardFormatListener` + `WM_CLIPBOARDUPDATE` |
| 源应用 | `NSWorkspace` / bundle ID | 前台窗口 PID + 进程名；排除项按进程名 |
| 粘贴 | 辅助功能授权后的定向粘贴 | 保存前台 HWND，恢复焦点后 `SendInput` `Ctrl+V` |
| 图片 | `NSPasteboard` 图片数据 | `PNG` 优先，`CF_DIBV5` / `CF_DIB` 转 PNG |
| 文件 | 文件 URL | `CF_HDROP`，只保存路径引用 |
| 敏感标记 | `org.nspasteboard.*` | Windows 隐私标记 + `org.nspasteboard.*` |
| 外观 | 系统 NSColor / 深色模式 | WPF 资源字典 + DWM 圆角/深色标题栏 |
| 设置 | SwiftUI Settings Scene | 无边框 WPF 设置窗口 |
| 数据 | Application Support + SQLite | `%LocalAppData%\cvMaster` + SQLite |

### 有意差异

- Windows 采用事件驱动而非轮询，空闲时不周期性唤醒 CPU。
- 浮层用 350 × 600 DIP 的独立窗口，而不是系统 popover；通过 `Deactivated` + 150 ms 定时器实现点击外部收起，并排除设置、确认框和右键菜单。
- 图片列表卡片使用 76 × 60 的缩略图，而不是 macOS 的 160 pt 横幅；这是为了在 350 × 600 浮层内同时保留更多条目。卡片仍然是“正文优先、来源沉底”。
- 浮层在远离托盘图标的一侧增加上下拖动把手，可把高度保存在 420–1000 DIP 之间；托盘在底部时手柄在顶部，托盘在上方时手柄在底部，拖动方向随之反转。macOS 版采用同一规则。
- 设置窗口使用左侧导航与三组页签，未复刻系统 TabView 的顶部标签栏，但保持同一信息分组。
- Windows 保留“自动粘贴”和“跳过敏感内容标记”两个开关：前者用于无法确认目标时退化为仅复制，后者对应 Windows 应用主动声明的隐私标记；macOS 端固定自动粘贴并始终跳过 `org.nspasteboard.*` 敏感标记。两者默认值均为开启。
- Windows 没有辅助功能授权与登录项审批流程；登录启动使用当前用户 `Run` 注册表项，状态立即生效。
- Windows 搜索使用转义 `LIKE`，不引入 FTS5；这是当前数据量与实现复杂度的有意取舍。

## 4. 剪贴板管线

### 4.1 事件与合并

1. `AddClipboardFormatListener` 注册消息窗口。
2. 收到 `WM_CLIPBOARDUPDATE` 后读取 `GetClipboardSequenceNumber()`。
3. 跳过自身写入序列、基线序列、暂停状态和排除来源。
4. 把“待读取”标记与最新来源写入字段，延迟 60 ms 由 STA 工作线程读取。
5. 读取前记录序列号，读取后再次比较；若期间又变化，则继续读取最新稳定快照，最多重试 3 次。
6. 只有稳定序列且不同于上次接受序列时才提交存储。

Windows 的 OLE 剪贴板写入经常产生两次连续通知（先清空、再写入）。如果对每条通知立即读取并在序列变化时丢弃，会把最终内容一起丢掉。合并策略是 Windows 版对原设计的关键适配。

### 4.2 受控格式

| 内部类型 | Windows 来源 | 说明 |
| --- | --- | --- |
| `text/plain` | `CF_UNICODETEXT` / `CF_TEXT` | UTF-16 优先；保留有界纯文本 |
| `text/url` | `UniformResourceLocatorW` | 无纯文本时补为文本 |
| `text/html` | `HTML Format` | 保留原字节；读取时校验大小 |
| `text/rtf` | `Rich Text Format` | 预览时解析可见文本 |
| `image/png` | `PNG` / `CF_DIBV5` / `CF_DIB` | DIB 转 PNG，限制像素数 |
| `windows/file-list` | `CF_HDROP` | UTF-8、NUL 分隔；最多 100 条 |

不采集自定义二进制格式、可执行内容或需要执行代码的格式。HTML/RTF 只作为文本表示，不执行脚本、不加载外部资源。

文件引用条目只保存 `windows/file-list`；若同一份剪贴板同时提供像素表示，则图片作为可选表示一并保存，不再写入同一份纯文本，避免部分应用把粘贴结果当成路径文本。必要表示超限时整条拒绝；可选 HTML / RTF / 图片超过单条或总预算时只跳过该表示，不丢弃仍可用的纯文本或文件引用。

### 4.3 入库

- 表示按 `(item, type)` 排序后计算 SHA-256 指纹；HTML 先提取正文，避免外层头部差异导致重复。
- 去重更新、保留期 / 容量清理和新记录写入在同一个 `BEGIN IMMEDIATE` 事务内完成；清理只删除非保护记录。提交成功后才回收被清理记录的资产文件，回滚不会丢失旧记录或旧资产。
- 资产先写入 UUID 命名的临时/最终文件，再提交数据库事务；失败回收本次新写入的资产。清空历史在事务内删除，随后 best-effort 回收孤立资产并 checkpoint，不执行全库 VACUUM。
- 数据库启用 WAL、`foreign_keys=ON`、2 MB 页缓存、1.5 s busy timeout。
- 搜索使用转义后的 `LIKE`，支持中文子串；不宣称 FTS 性能。

## 5. 数据与容量

| 对象 | 限制 |
| --- | --- |
| 首屏 | 60 条 |
| 最大加载 | 300 条；收起后缩回首屏 |
| 单表示 | 8 MB |
| 单条表示总量 | 16 MB |
| 表示数量 | 24 |
| 可搜索文本 | 32,768 字符 |
| 详情文本 | 16 KB |
| 列表缩略图 | 96 px，缓存 24 张 / 2 MB |
| 预览缩略图 | 420 px |
| 图片像素 | 24,000,000 |
| 文件引用 | 100 条；引用图片文件最大 64 MB |
| 历史总量 | 10,000 条 / 1 GB 表示字节 |
| 日志 | 单文件约 256 KB，滚动一份 |

单个 SQLite 连接配一个 `SemaphoreSlim`，所有查询在后台串行执行。UI 只接收最多 300 条轻量投影，不持有原图、文件句柄或完整正文。缩略图按需解码并限制并发为 2。

自动清理与入库共享事务：按保留天数移除过期记录，再按条数/容量移除未置顶、未分组的旧记录；重复复制同样执行保留期清理。置顶与已分组内容不会被自动清理；若保护内容占满容量，则拒绝新增并反馈。手动清理不受保护规则限制，需要二次确认。清理提交后只做 best-effort 资产回收与 checkpoint，不执行全库 VACUUM。

缩略图解码与引用文件读取在存储队列外执行，最多两个真实工作；调用方最多等待 3 秒后显示占位，超时路径在本次运行内不再重试。超时只停止等待，未结束的系统调用继续占用工作名额，避免异常挂载点不断派生阻塞线程。

### 实测基线

2026-10-19 在本机（Windows 11 build 26300，x64，125% DPI，空历史，发布版启动 4 秒后）测得：

- 工作集约 103 MB，私有内存约 54 MB。
- 24 个线程、约 1,046 个句柄。

工作集包含 WPF / .NET 共享运行时页面，且会随字体缓存、图片解码和系统组件变化；这不是任何机器上的常驻内存承诺。当前尚未测量 10,000 条历史、连续图片复制和长时间待机后的峰值。

## 6. 安全与隐私

### 6.1 默认关闭

首次运行 `RecordingEnabled=false`。浮层显示明确开启按钮；开启前不读取、不追溯当前剪贴板。暂停、关闭记录和清空后都会重置序列基线，避免把已有内容补录。暂停状态跨重启保存；恢复记录、锁屏 / 切换会话后只推进基线，不补采期间内容。

### 6.2 敏感标记

启用“跳过敏感与瞬时内容”后，遇到以下格式直接跳过：

- `ExcludeClipboardContentFromMonitorProcessing`
- `Clipboard Viewer Ignore`
- `CanIncludeInClipboardHistory=0`
- `org.nspasteboard.ConcealedType`
- `org.nspasteboard.TransientType`
- `org.nspasteboard.AutoGeneratedType`

前两个标记视为“永远不要读取”，不受开关影响；其余标记在开关开启时生效。

### 6.3 来源排除

默认排除 `1Password.exe`、`Bitwarden.exe`、`KeePass.exe`、`KeePassXC.exe`，可在设置中从运行中应用、已安装 `.exe` 或手动输入添加。只保存进程名，不保存可执行文件路径。

来源应用通过前台窗口 PID 与进程名推断，可能出错；排除规则不是安全边界，已有历史不受新增排除影响。

### 6.4 粘贴

- 打开浮层时记录最近一个外部前台窗口；点击托盘或本应用窗口不会丢失目标。
- 读取内容前先校验目标 HWND 仍存在、PID 未变、目标不是本进程，且前台仍是目标或本应用；第三方应用已在前台时拒绝，不抢焦点。
- 读取目标进程令牌完整性级别；目标级别高于当前进程时拒绝发送，避免静默失败或跨权限边界。
- 收起浮层后恢复目标窗口，等待其实际成为前台、本应用失活、修饰键释放并连续稳定 100 ms，最长 2.5 秒；准备成功后才改写剪贴板。
- 写入后再次同步校验目标仍为前台，再定向发送 `Ctrl+V`；检查与派发之间不再等待。
- 写入前失败时保留原剪贴板和原列表；写入后发送失败只提示手动粘贴，不记录使用次数。
- 失败后仅当原目标仍存活且前台仍是目标或本应用时才重开列表；否则只用托盘气泡说明，不以浮层抢走第三方应用焦点。
- 只有明确的 `Enter`、双击或菜单操作会粘贴；失焦不会触发自动粘贴。

### 6.5 日志与网络

`AppLog` 只写时间、级别和错误码，例如 `capture-Storage`，不写正文、路径、进程名或窗口标题。日志写入失败不影响主流程。应用没有任何网络客户端、更新检查或遥测。

### 6.6 未覆盖的风险

- 数据未做应用级加密；能读取当前用户文件的程序可以读取历史。
- 删除仅移除应用资产与数据库记录，不等于安全擦除系统备份/卷影副本。
- 敏感标记依赖应用主动声明，无法保证过滤所有密码。
- UIPI 下无法粘贴到更高完整性级别窗口；未提供绕过。
- HTML/RTF 预览只提取文本，不渲染原始富文本，避免外部资源与脚本。
- 锁屏 / UAC 通过输入桌面是否可访问来判断；Windows 没有 macOS Secure Event Input 的等价能力，密码框保护仍依赖应用主动标记。
- 数据目录拒绝符号链接 / 目录联接等重解析点，并校验资产只有单个硬链接；但不额外收紧 Windows ACL，同用户进程访问仍不在防护范围内。

## 7. 界面

### 7.1 浮层

- 350 × 600 DIP，可调高度 420–1000 DIP；无边框、置顶、不显示任务栏按钮。
- 初始位置锚定托盘图标上方，空间不足时放到下方；多显示器按目标显示器 DPI 换算。
- DWM 圆角与深色标题栏属性；边框与内容使用主题资源。
- 从上到下：品牌/更多、搜索/时间筛选、分组胶囊/类型筛选、记录横幅、分组列表、加载更多、状态栏；缩放手柄根据托盘相对位置动态放在顶部或底部。
- 卡片内容优先、来源沉底；选中态为 1.5 px 铜橙边框与浅色底，悬停为 1 px 铜橙边框。
- 悬停 280 ms 打开侧边预览，离开 200 ms 后关闭；预览可进入并选中文本。
- 空状态、加载中、记录关闭横幅、暂停胶囊均有明确状态；暂停时点击右上角“已暂停”胶囊可直接恢复记录。
- 空状态文案与 macOS 对齐（“还没有内容” / “没有找到内容”，提示“换个分组、时间范围或关键词试试。”）；加载到 300 条时提示搜索缩小范围。
- 列表行向 UI Automation 暴露合并后的整行语义（置顶、类型与正文或文件名、来源应用），避免子元素重复朗读。

### 7.2 主题

浅色：暖白背景、白卡片、低饱和铜橙强调；深色：暖灰背景、深灰卡片、浅铜橙强调。字体优先 Segoe UI Variable，回退 Segoe UI / Microsoft YaHei UI。主题资源通过 `DynamicResource` 替换，窗口、菜单、滚动条与设置页同步更新。

### 7.3 设置

三组页签：

- **通用**：记录开关、自动粘贴、登录启动、全局热键录制、跟随系统/浅色/深色。
- **记录与隐私**：敏感标记开关、排除应用列表、运行中/安装应用/手动输入、移除确认、隐私说明。
- **存储与清理**：条数与容量、进度、保留天数、按时间清理/清空全部、二次确认。

设置项立即持久化到 `HKCU\Software\cvMaster`。热键录制期间临时注销旧组合；组合必须包含 Ctrl、Alt 或 Win，仅 Ctrl 会与复制粘贴冲突。校验或注册失败时保留原快捷键并继续录制，可直接重试，Esc 取消。

## 8. 生命周期

1. 命名互斥量 `Local\cvMaster.Instance` 保证单实例；第二实例唤醒第一个实例的浮层。
2. 读取设置，应用主题，初始化 SQLite。
3. 创建视图模型、浮层、托盘与全局热键。
4. 注册剪贴板监听、前台窗口钩子和系统主题事件。
5. 首次运行显示托盘气泡提示，不自动打开浮层。
6. 退出时停止监听、释放托盘图标、注销热键、关闭数据库；日志只记录启动/退出代码。

UI 线程只做轻量投影和视图更新。剪贴板读取在专用 STA 线程，存储与缩略图解码在线程池；所有跨线程回调都切回 Dispatcher。
