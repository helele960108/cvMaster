# 隐私与数据说明

本文说明 cvMaster 在 macOS 与 Windows 上实际保存、读取和可能外发哪些数据，以及用户如何关闭记录、清理和降低风险。它是技术说明，不构成法律意见。

**最后更新：2026-11-04**

## 一句话概要

cvMaster 是本地优先的剪贴板历史工具：**默认不记录**，用户明确开启后只采集新的剪贴板变化；历史、设置和原始内容保存在本机，不提供账号、云同步、遥测或主动上传功能。数据未做应用级加密，删除也不等于安全擦除。

## 1. 默认不记录

- 首次安装或首次启动时，记录功能默认关闭。
- 开启记录时，应用从当前剪贴板状态建立基线，**不会回溯保存开启前已经存在的内容**。
- 暂停记录、系统睡眠、会话不在前台、登录未完成或系统安全输入启用时，应用跳过采集；恢复后也不会补采期间的内容。当前 macOS 版没有独立的锁屏标志检查，锁屏期间的阻断依赖会话 / 安全输入信号，不能保证覆盖所有锁屏状态；Windows 版在安全桌面不可访问时保守跳过。
- 关闭记录不会删除已有历史；需要删除时请使用“清理历史”或“清空全部历史”。

## 2. 会采集什么

在记录开启且未暂停时，应用会读取剪贴板中的受支持表示：

| 类型 | 保存内容 |
| --- | --- |
| 文本 | 纯文本内容、标题 / 摘要、可搜索文本 |
| 链接 | URL 及可用的纯文本表示 |
| 图片 | PNG / TIFF / JPEG 等受支持位图的原始数据与缩略图 |
| 文件引用 | 文件 URL（路径）与文件名；**不复制文件本体** |
| 富文本 | RTF / HTML 原始表示；HTML 不执行、不加载远程资源 |

同时保存以下元数据：

- 来源应用的显示名称；
- macOS 的 Bundle ID 或 Windows 的进程名；
- 复制时间、大小、复制次数；
- 置顶状态与用户创建的分组。

应用对单种表示、单条内容、条目数量和总容量设有上限，超限内容会被拒绝或截断；具体数值见各平台 README 与实现约束文档。

## 3. 不会主动采集什么

应用会识别并跳过以下情况：

- **macOS 隐私标记**：`org.nspasteboard.ConcealedType`、`org.nspasteboard.TransientType`、`org.nspasteboard.AutoGeneratedType`。
- **Windows 隐私标记**：`ExcludeClipboardContentFromMonitorProcessing`、`Clipboard Viewer Ignore`；默认还会尊重 `CanIncludeInClipboardHistory=0` 与常见 conceal / transient / auto-generated 格式。
- **默认排除应用**：
  - macOS：1Password 7、1Password、Apple Passwords；
  - Windows：1Password、Bitwarden、KeePass、KeePassXC。
- 用户自行添加的排除应用。
- 记录关闭、暂停、系统睡眠、会话不可用、安全输入启用或安全桌面不可访问期间的剪贴板变化。

这些标记和排除规则**不是绝对安全边界**。并非所有密码管理器、浏览器或应用都会设置标记；从不受支持的应用复制的敏感内容仍可能被保存。处理敏感信息前，建议暂停记录或使用排除应用。

## 4. 数据保存在哪里

### macOS

- 数据目录：`~/Library/Application Support/cvMaster/`
- 主要文件：`history.sqlite`、`assets/`、`assets/` 下的原始表示、`.instance.lock`
- 设置：当前用户的 `UserDefaults`
- 权限：应用会把数据目录收紧为 `0700`，数据库、WAL / SHM / journal 与资产文件为 `0600`；拒绝数据目录、资产目录、数据库及 sidecar 的符号链接。

### Windows

- 数据目录：`%LOCALAPPDATA%\cvMaster\`
- 主要文件：SQLite 数据库、`assets\` 下的原始表示、`logs\cvmaster.log`
- 设置：当前用户注册表 `HKCU\Software\cvMaster`
- 权限：数据位于当前用户配置目录，继承该目录的 Windows 访问控制；应用没有额外创建管理员权限或系统服务。

两端都不会把数据写入项目仓库、安装目录或共享目录。

## 5. 是否加密

**没有应用级静态加密。** 数据库和资产文件以明文形式保存在本机磁盘上，依赖操作系统账户隔离和磁盘加密保护。

建议：

- macOS 开启 FileVault；
- Windows 开启 BitLocker 或设备加密；
- 使用独立的本机账户，避免与他人共享同一账户；
- 不要把数据目录同步到不受信任的云盘或版本库。

## 6. 保留、删除与“安全擦除”

- 默认保留期为 **30 天**；可在设置中选择 7、30、90、180、365 天或永久保留。
- 自动过期清理在**写入新内容时**执行，与入库处于同一事务。应用长时间不运行、或没有新的复制内容时，过期条目可能继续留在磁盘上。
- 置顶条目和已分组条目**不参与自动过期清理**；它们仍占用条数 / 容量上限。
- 达到条数或容量上限时，应用会优先清理未置顶、未分组的最旧内容；保护内容占满上限时拒绝新增。
- 手动“清理历史”可以按时间删除记录，并包含所选时间点之前的置顶与分组内容；分组结构会保留。
- “清空全部历史”会删除数据库记录与资产文件，但**不会**：
  - 清空系统剪贴板；
  - 删除应用之外的文件、备份、系统快照或云同步副本；
  - 对 SSD、WAL、SQLite 空闲页或操作系统缓存做安全擦除。

如果需要彻底移除：退出应用、删除数据目录，并检查系统备份 / 快照中的旧副本。

## 7. 日志与崩溃材料

- 应用日志**不记录剪贴板正文、完整文件路径或密钥**。
- Windows 日志只记录时间、级别和固定错误码；异常只记录异常类型，不记录异常消息或堆栈；日志超过 256 KiB 会滚动保留一个备份。
- macOS 使用系统统一日志记录应用激活事件（不含进程标识）、粘贴阶段、错误码和必要的焦点交接状态；粘贴目标的 PID 以私有值记录。用于诊断自动粘贴；不记录输入框内容、剪贴板内容或文件名。
- 应用没有内置的“一键上传诊断”功能；提交问题前请自行检查并脱敏日志、截图和复现材料。

## 8. 网络行为

- 应用**没有账号、云同步、遥测、广告或崩溃上传**。
- macOS 版不包含第三方网络依赖；Windows 版不包含 HTTP 客户端或后台网络请求。
- HTML 只作为原始表示保存，不在 WebView 中渲染，也不加载其中的远程图片、脚本或样式。
- 检查外部文件引用是否可读时，操作系统可能访问本地磁盘、挂载的云盘或网络共享，并可能触发系统认证或元数据请求。这不是应用主动上传内容，但**不应把“无遥测”理解为“任何文件系统操作都不会产生网络流量”**。
- macOS 的文件引用可读性检查只接受文件 URL；Windows 的文件引用检查可能访问用户复制进来的路径。对网络路径有顾虑时，请避免复制网络共享中的文件。

## 9. 系统权限

### macOS

- **辅助功能**：自动粘贴需要读取目标应用的窗口 / 焦点元数据并发送 `⌘V`，因此需要辅助功能授权；不读取输入框内容、选区或文件内容。仅记录剪贴板不需要该权限。
- **登录项**：可选，由系统 `SMAppService` 管理；不安装额外 LaunchAgent。
- 当前版本为非沙盒的本机预览版，不申请“完全磁盘访问”。

### Windows

- 以当前普通用户权限运行，不请求管理员权限；
- 不安装服务、驱动或计划任务；
- 自动粘贴会拒绝目标进程完整性级别高于当前进程的情况。

## 10. 已知限制

- 敏感标记、来源排除和会话 / 安全输入信号都不能保证识别所有敏感内容；macOS 当前没有独立的锁屏标志检查。
- 暂停、关闭记录、新增排除、清空或删除发生在一次采集 / 粘贴已经进入保存或准备流程之后时，状态变化只阻止后续操作；已经开始的那一次仍可能完成提交。需要立即停止时，请先暂停记录并等待当前操作结束。
- 自动粘贴依赖目标应用的前台状态、active 状态和修饰键状态；有原窗口 / 输入节点快照时会先恢复并校验，窗口或输入框变化时拒绝，快照不可用时由当前 responder 决定接收位置。系统焦点检查与按键投递不是原子操作，不能保证目标应用一定接收。
- 文件引用只保存路径，原文件移动、删除、权限变化或云文件未下载后无法恢复。
- 图片预览与缩略图受格式、大小和本地卷限制；不保证处理所有私有格式。
- 应用不提供跨设备同步、账号、移动端或团队共享。
- 未实现应用级加密、硬磁盘配额或安全擦除承诺。

## 11. 安全报告

如果你发现隐私泄露、越权读取、粘贴目标错配或其他安全问题，请不要在公开 Issue 中粘贴真实剪贴板内容、数据库、日志或截图。报告方式见 [SECURITY.md](../SECURITY.md)。

## 12. 文档变更

本说明会随实现变化更新。涉及数据范围、默认值或网络行为的变更，应在 Pull Request 中同时更新本文和 README。
