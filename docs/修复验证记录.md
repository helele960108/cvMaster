# 深度修复与隔离验证记录

> 日期：2026-10-20
>
> 范围：性能、注释 / 文档一致性、剪贴板隐私及本地存储安全。没有启动应用、安装新版、采集真实剪贴板、打开真实历史库、修改用户偏好或提交 / 推送代码。

## 修复范围

- **搜索**：schema v4 稳定分类键；可选 FTS5 trigram external-content 索引，短语候选加原始转义 LIKE 复核；短查询 / 能力缺失回退；过期查询取消检查；分页关联批量查询、容量统计缓存。
- **存储**：DB 在 SQLite 打开前以 0600 创建；目录 / DB / WAL / SHM / journal / 资产使用所有者、普通文件、no-follow、单硬链接检查及私有权限；目录描述符相对资产读写和删除；根目录 / assets inode 更换时拒绝操作。
- **一致性**：自动清理、去重更新和新内容入库共享事务，旧资产提交后才删除；清空成功与后续 best-effort 维护分离，不执行全库 VACUUM；所有 SQLite 迭代检查失败，避免不完整资产扫描误删。
- **资源边界**：缩略图固定最多两个真实工作、零排队，同源同尺寸合并、取消 / 超时保留未结束工作许可、有界失败冷却；stored 420 / 640 px 缓存共用 24 张 / 2 MiB；引用可读性检查移出 actor 并限制工作数 / 等待时间。
- **采集隐私**：公开安全输入及会话状态保守门禁、恢复不补采、暂停状态持久化；读取前后检查版本 / 标记；必要表示优先，不能悄悄恢复缺项的多文件。
- **粘贴**：后台串行 AX 身份捕获 / 校验，原窗口 / 原输入节点严格一致；准备完成后才写剪贴板，写后再次验证并定向 PID 投递，不写未公开辅助功能属性。延迟读取及焦点交接的请求绑定另有纯状态策略验证。
- **RTF**：普通格式保存 / 恢复不变，纯文本转换共享 256 KiB RTF 输入解析预算，超限明确失败，不截断输出，不限制同大小纯 UTF-8 文本。
- **构建 / 文档**：本地签名启用 hardened runtime，不隐式联网获取时间戳；保留现有 bundle ID / TCC / 登录项身份。修正文档中 152 / 640 px、行尾箭头、锁屏、超时、加密、空间回收等过时或过度承诺。

## 已执行的隔离回归

命令：

```bash
./native/scripts/check-regressions.sh
./native/scripts/check-regressions.sh --benchmark
./native/scripts/check-regressions.sh --benchmark-large
```

验证器仅编译模型、存储、纯策略和缩略图相关源码，以独立 `@main` 命令行程序执行，不使用 XCTest 测试类。runner 只清理自己创建并带所有权标记的 mktemp 目录。

最终不带基准参数的验证中，以下 **11 组回归均通过**（退出码 0）。两个基准命令此前均正常退出、各通过当时的 10 组回归；新增焦点交接策略不涉及存储 / 搜索代码，因此没有重复运行大数据基准：

1. 稳定分类键与合成 v3 → v4 迁移，保留置顶、分组、复制次数及未知原始分类值。
2. 文本 / 链接 / 图片 / 多文件表示往返、去重、容量统计及元数据保留。
3. **38 个搜索语义用例**：trigram 可用路径和强制 LIKE 回退，覆盖中文、短词、引号、反斜杠、字面 `%` / `_`、换行及 Unicode 大小写。
4. 批量分组投影、无匹配计数、时间 / 类型 / 分组叠加筛选及 LIMIT。
5. SQLite 故障注入后的清理 / 入库回滚，保护条目保留。
6. 元数据 / 资产私有权限；根目录、assets、DB / sidecar 的符号链接、硬链接、目录、FIFO，以及运行时 assets 更换等临时攻击夹具不越界读写。
7. 单条及多 item RTF 聚合预算、超限原格式仍可恢复、大纯文本不受 RTF 预算影响。
8. 全量 / 按时间清理保留分组结构、不删除外部原文件，维护失败不作为删除回滚。
9. 确定性缩略图同源合并、固定工作上限、超时 / 取消后许可保留、实际完成后恢复。
10. 纯采集门禁、阻断 / 恢复基线、敏感标记、可选超大表示跳过、必要 item 完整性和数量 / 总量限额。
11. 纯粘贴请求状态交接：内容加载期间切换应用 / 关闭浮层会失效、切走再切回不复活、预期恢复事件延迟确认、原应用一直在前台时无需等待新事件、单次激活例外、目标 UUID / PID / 面板代数绑定及结束失效。

额外使用临时夹具验证了缩略图真实图像尺寸、stored / referenced 及外部图片叶节点符号链接、FIFO / 超限拒绝、失败冷却 / 过期 / reset、计时器不会污染后续同键工作，以及 2 MiB 编码输出截止。AX 工作许可的临时纯调度测试覆盖卡死任务截止返回、占用时拒绝、新工作恢复和 1,000 次完成 / 计时器竞态；这些不是跨应用 AX 行为验收。

### 验证过程中修正的问题

- 实际编译发现 actor 的普通 `deinit` 不能访问 non-Sendable SQLite 指针；改为当前 Swift 6.4 支持的 `isolated deinit`，未以 unsafe Sendable 指针绕过隔离。
- 首次整体验证遇到源文件同时更新，稳定副本重跑后通过，不将该次中断算作通过。
- 首轮隔离迁移夹具在 SQLite 打开阶段失败，而非迁移 SQL 失败。Foundation 的 URL 标准化将 `/private/tmp` 重写为 `/tmp` 符号链接别名，触发 `SQLITE_OPEN_NOFOLLOW` 拒绝。runner 使用 `pwd -P` 生成物理临时路径，验证器不再重新标准化；未削弱生产 no-follow 检查。注入目录同样应使用没有祖先别名的物理路径。

## 搜索基准

环境：Apple M4，10 核，16 GiB 内存，macOS 26.6.2（25G83），Swift 6.4，SDK 27.0、deployment target macOS 26.5，系统 SQLite 3.51.0。

方法：每个文本长度使用同一个逐步填充的临时数据库，分别达到 1,000 / 5,000 / 10,000 条。内容为重复的 ASCII / 中文及标点混合文本，约每 97 条加入选择性关键词；事务批量构造后 checkpoint。每个查询预热一次，再测 15 次，P95 按 nearest-rank 取第 15 个样本（即本组最大值）。

“生产 page”包含真实 actor 调用、分页投影、分组关联及统计路径；“LIKE 基线”仅执行匹配计数和 ID 查询，工作更少。因此数据用于观察索引选择的收益 / 退化，不能解释为严格同工作量的前后版本比较，也不是 UI 延迟、冷盘性能或 Instruments 内存结果。重复合成文本不代表最坏 trigram postings 分布。

### 10,000 条 × 每条 2,048 字符

取独立 `--benchmark` 运行，单位为毫秒（P50 / P95）：

| 查询 | 生产 page | LIKE 计数 + ID |
| --- | ---: | ---: |
| `selective-needle` | 1.13 / 1.43 | 30.35 / 33.17 |
| `not-present-anywhere` | 0.41 / 0.58 | 40.81 / 42.44 |
| 高频 `中文检索` | 29.62 / 32.24 | 10.76 / 13.93 |
| 单字 `中` | 9.77 / 11.09 | 10.30 / 11.37 |
| 两字母 `AS` | 9.85 / 10.30 | 10.56 / 11.12 |
| 字面 `_%` | 17.38 / 19.37 | 35.02 / 39.21 |

下表选择性查询数据来自 `--benchmark-large`，磁盘为同次运行中 SQLite / WAL / SHM 的文件逻辑大小，不包含真实资产或引用文件；构造耗时为本次新增批次加 checkpoint 等准备工作，并非完整逐条业务入库耗时。

**结论**：选择性和无匹配的长查询显著改善，但高频词的 trigram 召回可比 LIKE 更慢，1–2 码点仍需扫描。未引入未经验证的自适应查询规划，不宣称所有搜索更快。索引没有整体硬磁盘配额，712 MB 只是这组夹具的测量值，不是最坏上限。

## 静态检查与构建

最终包含焦点交接修复的 16 个 Swift 源文件已在稳定副本执行 Swift 6 严格并发 / warnings-as-errors 类型检查及 `-O` 实际编译链接，临时 `.app` 使用 ad-hoc hardened runtime 签名，并通过 `codesign --verify --deep --strict`；没有启动临时包。脚本 `bash -n`、Info.plist `plutil -lint` 和 `git diff --check` 通过。最终定向只读复核确认：内容加载前绑定原请求，恢复原应用前拒绝过期请求，正常激活通知明确确认，第二次同步检查不重新收养目标，两个已发现的焦点交接竞态均已修复。

## 仍未完成的产品验收与明确边界

- 未进行真实来源应用交互、AX 兼容性、焦点切换、权限撤销、系统安全输入或锁屏流程的端到端验收。合成策略测试不能代替它们。
- 未测最低硬件 UI P95、冷启动 / 冷盘、长时间空闲 CPU、进程 RSS 峰值和 ImageIO 内部峰值内存。
- 会话通知不等于锁屏保证，来源排除 / 敏感标记不保证识别所有密码。
- timeout 只释放等待者，不硬取消文件系统 / AX 调用；永久阻塞会耗尽有限工作槽，但不会不断派生线程。
- 本地普通资产读写、SQLite step 和有界 RTF 解析仍在存储 actor 同步执行；异常系统调用没有硬实时保证。
- 不提供应用级静态加密、整体硬磁盘配额或安全擦除承诺；不改变 bundle ID、系统授权和登录项身份。
- 递增 LIMIT 分页在最多 300 条 UI 上限内保留，未改为 keyset 分页；列表 / 详情两个尺寸不跨尺寸合并原图解码。
